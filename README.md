# 💱 Conversor de Moedas

> 💡 Este projeto faz parte da minha jornada como Desenvolvedor Web.
> Cada aplicação foi desenvolvida para resolver um problema real ou simular desafios encontrados no mercado, buscando aplicar boas práticas, evolução técnica e foco na experiência do usuário.

---

## 📖 Sobre o projeto

O **Conversor de Moedas** é uma aplicação web desenvolvida para realizar conversões entre diferentes moedas de forma rápida, intuitiva e responsiva.

Embora tenha surgido como um projeto de estudo em JavaScript, decidi expandi-lo e personalizá-lo, transformando um exercício de curso em uma aplicação com identidade própria, interface moderna e suporte para diferentes moedas.

Este projeto representa o encerramento do meu ciclo de estudos em JavaScript Vanilla e consolidou diversos conceitos fundamentais que servirão de base para aplicações cada vez mais complexas utilizando React e Node.js.

---

## 🎯 Objetivo

Criar uma aplicação web capaz de converter diferentes moedas de maneira simples, permitindo praticar lógica de programação, manipulação do DOM e atualização dinâmica da interface.

---

## 🎯 Desafio

O principal desafio deste projeto foi estruturar uma aplicação que realizasse múltiplas conversões de forma organizada, mantendo o código limpo, reutilizável e fácil de evoluir.

Além da lógica de conversão, procurei melhorar a experiência do usuário através de uma interface intuitiva e de uma organização mais profissional do projeto.

---

## ✨ Funcionalidades

- 💱 Conversão entre diferentes moedas
- 🇧🇷 Real (BRL)
- 🇺🇸 Dólar (USD)
- 🇪🇺 Euro (EUR)
- 🇬🇧 Libra Esterlina (GBP)
- 🪙 Criptomoedas
- 📱 Layout Responsivo
- ⚡ Atualização dinâmica dos valores
- 🚀 Deploy na Vercel
